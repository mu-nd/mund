# Changelog

Changes of the **data**. Version numbers follow `docs/versioning.md`:
a new major version is a frozen public release, a minor version adds data,
a patch version corrects existing entries.

## 0.1.0 - 2026-11-16

- First content of the repository: the data shown by the project's previous
  explorer (see `docs/migration-notes.md`), in the format described in
  `docs/data-format.md`.
- LT sub-library: 67 experimental values (Suzuki 1987, Mizuno 2025),
  8 curated values, 580 evaluated values (Iwamoto 2025).
